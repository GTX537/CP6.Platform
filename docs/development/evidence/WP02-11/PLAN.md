- [x] `HttpV2/Cp6HttpV2Profile.cs`: immutable named-client profile, original method classes, bounded retry/attempt/total/circuit settings, immutable policy version, explicit retry mode. Match named-client registration, reject conflicting or stacked legacy/v2 retry ownership, and make HttpClient.Timeout infinite only for the opted-in client whose v2 pipeline owns the total budget.
- [x] `HttpV2/Cp6HttpDeadline.cs`: TimeProvider timestamp/elapsed budget and caller token, UTC for observation only, inherited child deadlines that cannot extend remaining time. Send/recovery/response reads share the same overall deadline. Keep timeout source identity separate from duration, including equal attempt/total values and unknown sources.
- [x] `HttpV2/Cp6RetryAfter.cs` and `Cp6RetryDecision.cs`: one field value, ASCII nonnegative delta seconds or IMF-fixdate/RFC850/asctime; OWS only, invariant calendar and UTC, RFC850 future-50-year rule; huge legal digits stop rather than overflow into an invalid/local fallback. Observe UTC and timestamp once; sample jitter once. Use `B=min(maxDelay,baseDelay*2^(k-1))`, `L=ceil(clamp(B*(1-j+2*j*u),0,maxDelay))`, earliest=`m0+max(S,L)`. Both decision and send require `W+A<=R`. No truncation of S by jitter or maxDelay; S>30000 stops. Early wakes keep waiting, late wakes recheck, cancellation sends no later attempt.
- [x] `HttpV2/Cp6HttpOperationBinding.cs`: trusted named-client authority/verifier seam and immutable per-operation identity (tenant, action, key, request version, exact body/digest, method, destination, credential/config/route epoch, receipt/query/retention and evidence references). Resolve capability through host-registered authority, not caller headers or booleans. Unproven writes remain Disabled. Never copy a stream and infer business idempotency. Keep original result reads distinct from authorization for new effects.
- [x] `HttpV2/Cp6HttpV2Handler.cs` and versioned outcome types: compose deadline, retry, circuit, attempt and response-read handling using current dependencies. Explicit strategy identities map equal-duration timeouts; caller cancellation propagates unchanged; unknown source stops. Immutable request snapshot is used for every permitted repeat. A sent write failure remains Unknown, queries the original receipt before any retry, and never switches tenant/key/body/digest/binding. CircuitOpen cannot downgrade prior Unknown to NotSent. Fixture authorities are labelled as library tests and never registered as production proof.
- [x] `HttpV2/Cp6SafeProblemPolicy.cs` and `Cp6SafeProblemWriter.cs`: bind safe registered definitions, endpoint-visible field and message-code allowlists; output registered text only, never exception/input strings. Enforce 32 fields, four messages per field, 256 characters per text and 16KiB serialized body; overflow falls back to a generic safe code/correlation, without truncating JSON. Validate trace/correlation; response started/aborted means no second body. Keep old writer and CRM/auth behavior intact. Add explicit compatible extension entry points only.
